# 知行 KnowDo for Mac

The Unity of Knowledge and Action · 知行合一

「知行」是个人任务管理中枢：任务表 + 倒计时 + 专注守卫，目标是知行合一。本仓库是它的 **macOS 版（v0.1 基本版）**，与安卓版共用同一个 Google Drive 桥文件 `tasks.json` 同步数据——手机上加的任务，Mac 上约 10 秒内出现，反之亦然。

设计语言与朋友合作的 Smart Countdown Timer 一脉：菜单栏常驻「任务名 + 剩余时间」、深色半透明悬浮小窗、极简全屏页（结束页 🏆 Time's up + 加时按钮带 Q/W/E 快捷键 + Mark Complete 回车确认）。安卓版后续也会借鉴这套风格。

## 功能清单（v0.1）

1、**主窗口任务表**：勾选框、任务名、情景、截止日期 + 完成时间 + ▶开始时间、时长 / 实 X 分、专注标记、▶/⏸、⋯ 菜单（编辑 / 完成 / 复制信息 / 重置计时 / 删除）；顶部「＋ 新任务」；点行打开编辑。
2、**编辑 sheet**：覆盖全部字段——标题、情景多选（常用集 + 自定义）、截止日期 + 完成时间 + 开始时间（日期时间选择器，可清除）、每日重复、计划分钟、实际分钟、优先级、备注、专注描述 / 模式 / 主应用 bundle id / 黑白名单。
3、**计时引擎**：全局最多一个计时中 + 一个暂停槽（与安卓语义一致）；到一半弹全屏检查页（继续计时 / 就此完成 / 暂停休息）；结束弹全屏 Time's up 页（+5/+15/+25 分钟带 Q/W/E 快捷键、自定义加时、Mark Complete 回车，完成写回 doneDates/status 经桥同步）。
4、**菜单栏**：常驻「☕ 任务名 剩余时间」，点击有小菜单（开始/暂停当前、打开主窗口、打开日历、退出）。
5、**悬浮面板**：置顶可拖、位置记忆，显示当前第一要务（计时中 ＞ 刚暂停 ＞ 列表第一未完成）：左侧剩余大字、右侧小字「已用 / 共计划」（已用 = 本机今日计时段累计）；按钮一排（开始/暂停、完成、打开知行）；笔记快速编辑停笔自动存，笔记框右上角有「复制」按钮（复制任务全部信息，排版与安卓一致）。可收起为只剩菜单栏（设置里有开关）。
6、**日历窗口**：今日纵向时间轴（05:00–23:00，可随内容扩展），左列计划块（桥 schedule，只读）、右列实际块（本机计时段，绿色），当前时间红线，顶部概览（已完成 X 件 · 未完成 Y 件 · 还可自由安排 Z 分钟到 22:30）；「问 AI」按钮把今日日程摘要 + 未排任务 + 排程规则拼成文本复制到剪贴板，去 Muse 里粘贴即可。
7、**开始时间提醒**：任务的 nextStartAt 到点弹全屏页（开始计时 / 延后 10 分钟 / 忽略；开始后清掉该次时间点写回桥）。
8、**autoStart**：桥端把某任务置 autoStart=true 后，Mac 端轮询发现且没在计时时自动开始计时，并回写 false。
9、**开机自动启动**：首次启动默认注册系统登录项（设置里有开关）；若注册失败（多半是 App 不在「应用程序」文件夹），把 App 放进去再到设置里打开。
10、**设置**：桥文件路径与重新选择、悬浮面板开关、登录项开关、关于（版本 / 许可 / 礼仪约定）。

**v0.1 明确不做**：专注守卫的拦截执行（focus 字段只同步与编辑）、屏幕内容守卫、Google Calendar、子任务。都在后续版本计划里。

## 构建与运行

1. 需要 macOS 14+ 和 Xcode（15 左右即可）。
2. 双击打开 `KnowDoMac.xcodeproj`，选 KnowDoMac scheme，直接 Run（⌘R）。
   - 工程用 ad-hoc 签名（CODE_SIGN_IDENTITY = "-")，本机运行不需要开发者账号。
   - 想长期用：Build 出的 KnowDoMac.app 拷到「应用程序」文件夹再打开，登录项注册才稳。
3. **首次启动**：主窗口会提示选择桥文件——选手机版用的同一个 `tasks.json`（在 Google Drive「_电子大脑 / task list」文件夹，需先在 Mac 上装 Google Drive 并把该文件同步到本地）。路径会以书签形式记住，之后不用再选。

## 与安卓同步的注意事项

- 两边改同一个任务时，**updatedAtMs 新者胜**；删除是墓碑标记，不会复活。
- Mac 端遵守和安卓 v1.5.3 同一套规矩：**没变化绝不回写**、写之前重新读一遍最新文件再合并、写完回读校验。所以不会再出现「新任务被旧版本盖掉」的事故。
- 顶层 `schedule` 由 Muse 维护，Mac 只读、永不生成或改动；`guardEvents` 只保留不删；桥里 Mac 不认识的字段一律原样保留。
- 写回时顶层 `updatedBy` 会标 `knowdo-mac`。
- 计时段（实际投入）是**本机本地记录**（存 `~/Library/Application Support/KnowDoMac/sessions.json`，上限 500 段），不进桥——和安卓口径一致：手机上计的时只出现在手机日历页，Mac 上计的只出现在 Mac 日历页；任务本身的完成状态是走桥同步的。

## 已知限制

- 同步靠每 10 秒轮询桥文件（Drive 本地副本），秒级实时需要日后换推送方案。
- App 退出期间计时不走字：计时中的任务在退出时落成「暂停」态，下次打开接着继续；崩溃残留的计时段按计划时长封顶估算。
- 主窗口被关闭后，点悬浮窗/菜单栏的「打开知行」只能激活 App，窗口请用程序坞图标点开重建。
- Time's up 页的自定义分钟输入框里，字母键 Q/W/E 是加时快捷键，不要在框里输字母（只输数字）。
- App 图标暂缺（Assets 里是空图标集），不影响运行。
- 本工程没有沙盒（App Sandbox 未开）：桥文件用 security-scoped bookmark 访问，将来若要上架 Mac App Store 需要再处理签名与沙盒。
